# 2026AIC-"AI+钢铁" 板材表面缺陷检测

> 注：本文档由 [原始网页](https://www.aicomp.cn/tracks/tracks-1/4174.html?_refluxos=a10&qq_aio_chat_type=2) 转写并整理而成。

## 一、应用场景

1. **生产流水线表面质量自动检测：** 在高速输送钢板的产线上，利用计算机视觉算法实时精准定位表面缺陷，例如裂纹、划伤、结疤等，实现实时喷标与分级，尤其适用于高产速产线。

2. **复杂工况下的伪缺陷过滤与精准识别：** 真实工业环境中常伴随严重干扰，例如水渍、油污、粉尘和脱落氧化铁皮。视觉模型应能够有效区分真实缺陷与由生产环境造成的伪缺陷，即使在水雾遮挡或复杂背景纹理条件下，也要保持高精度感知。

3. **在其他产线上的稳定运行：** 现有模型常因域差异而表现欠佳，这是由于不同产线在相机硬件、光照条件、产品类型和厚度规格等方面存在明显差异。具备强泛化能力的视觉算法应能有效克服这些跨域挑战，使模型能够快速适应新的产线和钢种。

> 在机器学习和数据科学中，域间差距（domain gap，或 domain shift）是指模型在一个数据集（源域）上训练后，应用到另一个相关但不同的数据集（目标域）时出现的性能下降。

## 二、任务

1. 缺陷检测与精确定位

  开发高精度视觉模型，准确识别金属板表面的各类缺陷：

  1. 纵裂 (Longitudinal Crack)：沿钢材轧制方向延伸的裂纹。
  2. 夹杂 (Inclusion)：困在钢材内部或表面的非金属外来颗粒。
  3. 麻面麻坑 (Pitted Surface)：钢板表面成簇分布的小型、不规则凹陷或坑洞。
  4. 氧化铁皮 (Mill Scale)：热轧过程中形成的片状氧化铁层。
  5. 辊印 (Roll Mark)：由轧辊损伤或沾污引起的周期性压痕或凸起痕迹。
  6. 异物压入 (Pressed-in Foreign Matter)：在轧制过程中被压入钢材表面的外部碎屑或颗粒。
  7. 划伤 (Scratch)：由尖锐物体机械摩擦造成的线状沟槽或划痕。
  8. 结疤 (Scab)：附着在钢板表面的壳状金属层，通常由浇铸飞溅引起。
  9. 气裂 (Gas Crack)：由被困气泡在加工过程中膨胀而引起的表面破裂。

  模型输出具体缺陷类别及其边界框坐标。Precision 和 Recall 是核心评价指标。部分缺陷类别示例如下：

1. 难样本与跨产线泛化优化

  面对极度不均衡的长尾数据（尤其是裂纹这类稀有但致命的缺陷），设计算法策略以最大化召回率，并消除任何漏检（false negatives）。

  > 长尾数据是指少数类别出现频率很高，而绝大多数类别出现频率很低的数据集。
  >
  > 当把它绘制成“类别频率”图时，左侧会形成高高的“头部”，右侧则拖着很长、很细的“尾部”。
  >
  > ```text
  >  频率
  > ▲
  > │  █
  > │  █ █                  ◄── “头部”：常见类别（如划伤、辊印）
  > │  █ █ █
  > │  █ █ █ █ ▄ ▄ ▄ _ _ _ _ _ _ _ _ _ _ _ _ _ _ ◄── “尾部”：稀有类别（如致命裂纹）
  > └──────────────────────────────────────────►
  >                                      类别
  > 
  > ```
  >
  > 自然界和工业场景天然会产生长尾数据。在钢铁制造中，轻微划伤每天都会出现（头部），但影响结构安全的关键裂纹却极少出现（尾部）。在这类数据集中，最稀有的类别（尾部）往往最关键，但也最难被 AI 学到。

## 三、输入/输出规格

### (一) 输入

- 图像数据：图像主要由超高分辨率工业相机采集（4096 × 3000 像素），格式为 .jpg 或 .png。
- 标注数据（PASCAL VOC 格式）：每张图片都配有一个同名的 .xml 标注文件。该文件包含图像的详细信息以及缺陷目标的精确位置。核心字段包括：

  - `<size>`：包含图像宽度、高度和通道数（深度）。
  - `<object>`：每个独立缺陷目标对应一个 `<object>` 块。
  - `<name>`：缺陷类别的拼音或英文缩写（例如 zonglie 表示纵裂，jiaza 表示夹杂等）。
  - `<bndbox>`：缺陷边界框坐标，由左上角（xmin, ymin）和右下角（xmax, ymax）组成，这些坐标值表示绝对像素位置。

### (二) 输出

模型需要处理测试集中的每一张图片。所有图片的预测结果应汇总并打包为一个 JSON 格式文件提交。评测系统将自动解析该 JSON 文件，并基于隐藏的 Ground Truth 标签计算评估指标，例如 mAP（Mean Average Precision）。

提交的 JSON 文件必须是一个 List，其中列表中的每个 Dictionary 表示一个预测出的缺陷目标。字段定义如下：

## 四、数据集与数据说明

### (一) 数据来源

本竞赛提供的数据集来自真实工业生产线数据。所有图像数据均来源于南京钢铁股份有限公司（中厚板等核心产线）的表面质量在线检测系统，在高速轧制工况下由高分辨率工业线阵相机实时采集。经过严格人工筛选和高精度专家标注后，构建了本次竞赛专用数据集。

所有数据均保证来源合法合规，并且仅被授权用于本次竞赛中的学术探索、算法验证和非商业用途。

### (二) 数据规模与划分

本竞赛提供的数据集约包含 5,000 张高分辨率工业图像。为全面、客观地评估参赛模型的性能，数据集将划分为训练集、初赛测试集、半决赛测试集和总决赛测试集。各阶段数据划分如下：

- **训练集：** 约包含 3,200 张带精确人工边界框标注的缺陷图像，用于参赛者训练计算机视觉检测模型。该训练集包含 9 个类别。由于类别间差异较小，训练集中对部分类别做了合并，包括：

| 合并后类别 | 原始类别 | 数量 |
| :--- | :--- | :--- |
| `scab` (结疤) | Scab, Double Skin, Roll Damage (结疤、重皮、轧损) | 604 |
| `longitudinal_crack` (纵裂) | Longitudinal Crack (纵裂) | 296 |
| `gas_crack` (气裂) | Bubble Crack, Transverse Crack (气裂、横裂) | 28 |
| `inclusion` (夹杂) | Inclusion (夹杂) | 113 |
| `pressed_in_foreign_matter` (异物压入) | Scale Dropping, Edge Press-in, Pit, Foreign Matter Press-in, Double-sided Shear Press Mark, Fixed-length Shear Press Mark (掉渣、边丝压入、压坑、异物压入、双边剪压痕、定尺剪压痕) | 464 |
| `scratch` (划伤) | Scratch (划伤) | 60 |
| `pitted_surface` (麻面麻坑) | Pitted Surface, Pit (麻面、麻坑) | 309 |
| `mill_scale` (氧化铁皮) | —— | 358 |
| `roll_mark` (辊印) | Bulge, Bump (鼓包、凸块) | 236 |

- **初赛测试集：** 约包含 800 张无标注图像，数据分布与训练集基本一致，用于初赛阶段的客观评估。

- **半决赛与总决赛测试集：** 约包含 1,000 张无标注图像。该部分数据引入了来自不同产线的复杂样本，用于考察模型在 **Domain Shift** 条件下的泛化能力。

### (三) 数据特征

该数据集高度还原了严苛的真实工业传感环境，具有以下显著特征：

1. **数据类型与尺度：** 数据由超高分辨率单通道灰度图像组成（典型分辨率为 4096×3000）。目标缺陷的尺度跨度极大，从横跨屏幕的长条状“纵裂（zonglie）”，到仅占几十个像素的微小“夹杂（jiaza）”都有。

2. **长尾分布：** 由于真实高质量产线上严重缺陷极为罕见，数据集中的类别呈现典型的长尾分布。常见的轻微缺陷样本相对充足，而致命缺陷样本则很少。

3. **复杂背景干扰：** 图像背景天然叠加了高强度伪噪声，例如水渍、油污、粉尘，以及实际生产线上的正常水刀切割痕迹。

### (四) 预处理说明

为了降低参赛者的数据清洗成本并让大家更专注于算法本身，主办方对原始采集数据进行了基础预处理：

1. **数据清洗：** 去除了由于相机光源高频闪烁产生的全黑/全白无效帧，以及完全没有意义的空背景帧。

2. **格式标准化：** 对不同底层传感器采集的 RAW 数据进行解码、对比度拉伸，并统一转换为标准 8 位 `.jpg` 格式图像。

3. **未进行裁剪与归一化：** 为保留缺陷的全局上下文信息，主办方没有强制裁剪或缩放归一化原始超高分辨率图像。参赛队伍需要根据所采用的基础大模型或目标检测网络（如 YOLO 系列）自行设计数据加载策略，包括 resize、crop 和 tensor normalization。

  > YOLO（You Only Look Once）是一类革命性的实时计算机视觉模型，它将目标检测建模为一个单一回归问题，而不是分类任务。与需要对图像进行多次局部处理的传统多阶段方法（如 R-CNN）不同，YOLO 只需将整张图像通过卷积神经网络（CNN）一次，即可同时预测边界框和类别概率，因而具备极高的处理速度，适合实时视频流场景。

### (四) 数据格式

竞赛训练数据集采用经典的 **PASCAL VOC** 格式组织。每组训练数据由一个图像文件和一个同名的文本标注文件组成。

- **图像文件：** 标准 `.jpg` 格式，命名规则如 `0001388270-Raw01-f_00001.jpg`。
- **标注文件：** 标准 `.xml` 格式。文件中包含图像的基本属性（宽、高、通道深度）以及缺陷目标的详细信息。

对于图像中的每个缺陷，标注信息都存储在 `<object>` 标签中。核心字段包括：

- `<name>`：缺陷类别的唯一标识符（例如 `longitudinal_crack`、`scab` 等）。
- `<bndbox>`：目标缺陷的绝对像素坐标边界框，由左上角 `[xmin, ymin]` 和右下角 `[xmax, ymax]` 的绝对整数值组成，取值范围位于 `[0, image width/height]` 内。

## 五、算法设计要求

### (一) 模型类型

鼓励参赛者采用并深度优化面向工业视觉场景的深度学习目标检测算法。优先支持以主流计算机视觉架构为核心的技术路线，包括但不限于：

- 基于卷积神经网络的高效检测算法（如 **YOLO 系列**）
- 基于 Vision Transformer 的检测模型（如 **DETR 系列**）等

这旨在充分发挥深度学习算法在精细特征提取、复杂背景抗干扰以及工业级高频实时推理方面的核心优势。

### (二) 创新方向

鼓励参赛队伍提出针对真实工业视觉检测痛点的创新改进方案，重点提升模型对多尺度缺陷的精确感知能力，以及跨产线的泛化能力。例如，为了解决钢板表面强伪缺陷干扰（如水渍、油污遮挡）或致命缺陷（如微小裂纹）漏检等问题，参赛者可设计专门的抗噪特征提取网络、多源特征融合机制，或 **Domain Adaptation** 模块，以增强模型在长尾分布数据下的识别精度和定位精度。

## 六、性能指标要求

本竞赛题目聚焦于钢板表面缺陷的精确检测。考虑到真实工业产线的业务需求是 **“允许少量误报，但严禁漏检”**，因此本竞赛采用 **Precision** 和 **Recall** 作为评估参赛模型性能的核心指标。

参赛者的算法模型必须在保证基础 **Precision** 的前提下，尽可能追求更高的 **Recall**。
